# 🍱 Cancerina Catering Website

Website resmi **Cancerina Catering**, layanan katering premium berbasis di Trenggalek. Website ini dirancang untuk memberikan pengalaman pemesanan yang cepat, visual menu yang menarik, dan kemudahan akses bagi pelanggan melalui fitur *Progressive Web App* (PWA).

## ✨ Fitur Utama
- **Responsive Design**: Tampilan optimal di semua perangkat (HP, Tablet, Desktop).
- **Fast Loading**: Dibangun dengan optimasi performa tinggi menggunakan Vercel Edge Network.
- **PWA Ready**: Dapat di-install langsung di layar utama HP pelanggan tanpa melalui Play Store/App Store.
- **Direct WA Integration**: Tombol pemesanan yang langsung terhubung ke WhatsApp admin.
- **Modern UI**: Menggunakan tren desain terbaru dengan Tailwind CSS v4.

## 🛠️ Teknologi yang Digunakan
- **HTML5** & **Modern JavaScript**
- **Tailwind CSS v4** (Framework CSS tercepat & tercanggih saat ini)
- **Vercel** (Hosting & Automated Deployment)
- **Service Workers** (Untuk dukungan PWA)
